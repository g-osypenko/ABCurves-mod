# План реализации рефакторинга промптами

Чтобы перевести архитектурный концепт в рабочий код с помощью LLM, процесс разбит на 4 изолированных шага:

### Промпт 1: Каркас архитектуры и очистка (Pruning)
- **Контекст для LLM**: Передайте «Таблицу аудита и прунинга репозитория». Укажите удаление папки `_continuous` и классификаторов `hazard.onnx`, `brake.onnx`, `choice.onnx`.
- **Задача**: Написать базовый класс `ClosedLoopProDMPController`. В конструкторе (`__init__`) инициализировать `FastPlanner` (с `motor.onnx`) и инстанс `PortableRendererStream`. Задать сигнатуры методов `on_target_update`, `step` и `reset`.

### Промпт 2: Модификация ProDMP для бесшовной склейки ($C^1$ сплайсинг)
- **Контекст для LLM**: Для управления с удаляющимся горизонтом (Receding Horizon) требуется строгая непрерывность первого порядка ($C^1$) между сегментами траектории.
- **Задача**: Модифицировать `FastPlanner` в `fast_planner.py`, добавив метод `get_analytical_state_at(delta_t)`. Метод использует базисные функции ProDMP для возврата аналитической позиции и производной (скорости) кривой в момент времени $\Delta t$.

### Промпт 3: Логика динамического обновления цели
- **Контекст для LLM**: Метод `on_target_update(target_offset, dt)`. Смещение передается в `FastPlanner` с параметром `goal_mode = 'target'`, чтобы динамическая система отработала как фильтр, минимизирующий рывок (minimum-jerk).
- **Задача**: Реализовать метод `on_target_update`. Он должен:
  1. Применить логистическую сигмоиду для затухания вектора при попадании в мертвую зону (inner deadzone).
  2. Вызвать `get_analytical_state_at` для получения начальной скорости.
  3. Сгенерировать новый план через `FastPlanner.plan(...)` и отправить сегмент (на 10–15 мс) в буфер `renderer_stream`.
  4. Обнулить внутренний таймер сегмента.

### Промпт 4: Высокочастотный шаг генератора (1000 Гц)
- **Контекст для LLM**: Описать логику шага генератора `step()` (1000 Гц). Указать, что даже если буфер дельт пуст, рендерер не останавливается.
- **Задача**: Реализовать метод `step()`. Метод забирает данные из `renderer_stream`. Если план исчерпан или цель в deadzone, выполняется холостой прогон (idle run). `Sigma-Delta` модулятор абсорбирует остаточный импульс, формируя логнормальный хвост замедления и накладывая тремор. Метод возвращает рассчитанные смещения траектории.
